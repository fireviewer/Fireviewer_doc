# Migration de la documentation FireViewer

Ce dépôt représente l’historique du développement initial de FireViewer.

Les dépôts actifs, l’architecture inter-dépôts, la roadmap et les statuts des composants sont désormais maintenus dans l’organisation GitHub [`fireviewer`](https://github.com/fireviewer).

## Dépôts actifs

- dépôt documentaire FireViewer — source de vérité inter-dépôts ;
- `fireviewer/fireviewer-frontend` ;
- `fireviewer/fireviewer-backend` ;
- `fireviewer/fireviewer-ai-worker` ;
- `fireviewer/fireviewer-spatial` ;
- `fireviewer/fireviewer-sdg`.

Ce dépôt ne doit plus servir de source de vérité pour la roadmap, le registre des modèles, les contrats inter-dépôts ou les procédures de déploiement courantes.
