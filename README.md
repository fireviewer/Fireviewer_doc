# FireViewer

**Open-source infrastructure for documented wildfire observation, spatial
reconstruction, temporal tracking, and reproducible post-event study.**

FireViewer is an independent research and engineering project maintained by
**Unicorn Who Dev**. It helps preserve sources, uncertainty, evidence, and
human review so that a documented event can be revisited without presenting a
hypothesis as fact.

> FireViewer is not an emergency alert service, an official source, a command
> tool, or a certified wildfire-propagation predictor. In an emergency, follow
> the relevant authorities and emergency services.
