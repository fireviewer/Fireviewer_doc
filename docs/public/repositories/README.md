# Fiches des dépôts FireViewer

**Inventaire vérifié le 19 septembre 2026 : 18 dépôts.** Le producteur cartographique UWD reste externe.

| Dépôt | Rôle |
| --- | --- |
| [fireviewer-frontend](fireviewer-frontend.md) | Application navigateur pour atlas public, contribution, revue, administration, chronologie et exploration 2D/3D. |
| [fireviewer-backend](fireviewer-backend.md) | Autorité incident-centred pour preuves durables, jobs, permissions, review, audit, révisions et publication. |
| [fireviewer-ai-worker](fireviewer-ai-worker.md) | Couche de compatibilité pour l’ancien namespace `firewarning_worker` et commandes historiques encore consommées. |
| [.github](github-profile.md) | Profil de l'organisation et politiques partagées de contribution, sécurité, support et conduite. |
| [Fireviewer_doc](Fireviewer_doc.md) | Source canonique pour architecture, maturité, gouvernance, données, repository map et statut du projet. |
| [fireviewer-contracts](fireviewer-contracts.md) | Contrats versionnés d’évidence, géométrie, reconstruction et clients backend bornés. |
| [fireviewer-evidence-ingestion](fireviewer-evidence-ingestion.md) | Acquisition et normalisation bornées des sources, médias, transcription et observations satellite. |
| [fireviewer-evidence-supervisor](fireviewer-evidence-supervisor.md) | Évaluation structurée des preuves, contradictions et décisions `accept`, `reject`, `abstain`; héberge Eve. |
| [fireviewer-fire-state](fireviewer-fire-state.md) | Calcul déterministe Part.4, profils de fusion, calibration et évaluation. |
| [fireviewer-geolocation](fireviewer-geolocation.md) | Production d’hypothèses géographiques par retrieval, perspective, registration, Panoramax et autres références. |
| [fireviewer-model-lab](fireviewer-model-lab.md) | Préparation des corpus, recettes d’entraînement, évaluations, benchmarks et registre des modèles. |
| [fireviewer-orchestrator](fireviewer-orchestrator.md) | Coordination stateless de l’exécution des stades sur un état durable possédé par le backend. |
| [fireviewer-unreal](fireviewer-unreal.md) | Visualisation spécifique feu et scénarios Unreal / Wildfire Studio. |
| [fireviewer-vision-runtime](fireviewer-vision-runtime.md) | Inférence spécialisée : détection, pointing, segmentation et extraction de keyframes. |
| [fireviewer-docker](fireviewer-docker.md) | Verrous d’images/versions, composition de services, recettes de reconstruction et preuves opérationnelles privées. |
| [fireviewer-association-site](fireviewer-association-site.md) | Source du site institutionnel `fire-viewer.fr`, distinct du viewer/administration des incidents. |
| [FIRE-VIEWER-gestion-android](FIRE-VIEWER-gestion-android.md) | Application Android native pour tâches, finances, remboursements, budget, services, financements, partenariats, documents, échéances et décisions. |
| [pointing-atelier](pointing-atelier.md) | Atelier Android et pipeline de préparation du corpus pointing/detection avec stockage des données sur Hugging Face. |
