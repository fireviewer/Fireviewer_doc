# fireviewer/fireviewer-unreal

**Visibilité :** privé
**Catégorie :** Visualisation/simulation
**URL :** https://github.com/fireviewer/fireviewer-unreal

## Rôle

Visualisation spécifique feu et scénarios Unreal / Wildfire Studio.

## État documenté au 19 septembre 2026

Conservé mais simulation en attente et hors chantier MVP actif. README vise UE 5.8.2 et plugin FVMapBuilder source 0.1.0.

## Entrées

Packages cartographiques et ressources autorisées.

## Sorties

Projet/source Unreal pour visualisation/scénarios lorsque le chantier sera repris.

## Dépendances / interfaces

Plugin générique FVMapBuilder maintenu séparément dans UWD map-builder.

## Vérification et reprise

Tests Python de préparation seulement; compilation UE, rendu, simulation et validation visuelle sont des portes séparées.

## Limites à conserver dans toute présentation

Ne pas introduire Unreal comme dépendance du site/atlas web. Tests Python ≠ réception native Unreal. Omniverse est sorti du périmètre.

## Règle de maintenance documentaire

Toute évolution qui change la responsabilité, un contrat public, un format de sortie, une limite de sécurité ou un identifiant compatible doit être reflétée dans le dépôt lui-même **et** dans la documentation canonique `Fireviewer_doc`. Une refonte documentaire ne doit pas être présentée comme une nouvelle preuve fonctionnelle.
