# FireViewer public documentation

This directory contains the public, maintained description of FireViewer. It
explains what the project does, how evidence moves through the system, which
safety rules are enforced, what data may be retained, and which capabilities
remain under development.

Detailed engineering plans, provider runbooks, cloud identifiers, private
evidence, machine paths, raw logs, credentials, and internal project tracking
remain local working material. Their exclusion does not make this public
documentation incomplete: the public pages describe the product, its safety
model, its verified maturity, and its open interfaces without publishing
operationally sensitive details.
