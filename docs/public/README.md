# FireViewer public documentation

This directory contains the maintained public technical description of FireViewer.

It explains what the system does, how evidence moves through it, which trust boundaries matter and what is actually implemented today.

Project governance and community policies are linked from this index but remain separate from the technical architecture documentation.
