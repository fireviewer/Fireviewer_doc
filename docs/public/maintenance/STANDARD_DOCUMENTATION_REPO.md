# Standard de documentation à appliquer à chaque dépôt

Chaque README ou fiche de dépôt maintenu devrait contenir, dans cet ordre :

1. **Rôle canonique** — une phrase ;
2. **Statut** — actif, expérimental, transitoire, archive, en attente ;
3. **Ce que ce dépôt possède / ne possède pas** ;
4. **Entrées et sorties** ;
5. **Interfaces et contrats versionnés** ;
6. **Installation/reprise minimale** ;
7. **Tests et ce qu'ils prouvent réellement** ;
8. **Limites de qualification** ;
9. **Sécurité / provenance / données sensibles** ;
10. **Licence, droits tiers et stewardship** ;
11. **Compatibilité / identifiants à ne pas casser** ;
12. **Liens vers la documentation canonique**.

## Règle importante

Les phrases « fonctionne », « validé », « production » ou « opérationnel » doivent toujours être associées à un périmètre et à une preuve datée. Si seule la présence du code est démontrée, écrire « implémenté ».
