# Standard FireViewer pour Model Card / Dataset Card

## Model Card

- nom + tâche ;
- statut exact : baseline, candidat, référence, expérimental, qualifié pour X ;
- modèle de base et révision ;
- corpus d'entraînement et révision ;
- classes/sorties ;
- protocole de benchmark, split et révision ;
- métriques comparables uniquement ;
- seuil : exemple ou calibré ;
- artefacts et hashes pertinents ;
- droits/licences code + poids + données ;
- usages prévus ;
- usages non établis ;
- limites/risques connus ;
- règle de validation humaine ;
- date de dernière évaluation réelle.

## Dataset Card

- objectif et nature du corpus ;
- sources et licences par famille ;
- volume réel ;
- classes/labels ;
- splits et stratégie de grouping ;
- déduplication/leakage ;
- transformations ;
- provenance/hashes ;
- annotations humaines vs automatiques vs faibles ;
- exclusions/quarantaine ;
- méthode de chargement ;
- révision ;
- limites ;
- restrictions de redistribution ;
- relation aux modèles qui le consomment.
