# FireViewer component documentation

Versioned component documentation is owned by the repository that implements
the component. It contains portable setup, source-level contracts and
contributor-facing verification guidance. This repository keeps the
cross-project doctrine, contracts and public status; it does not mirror
component runbooks because copied snapshots drift away from the code they
describe.

| Component | Developer documentation |
| --- | --- |
| Frontend | [`fireviewer-frontend/docs`](https://github.com/fireviewer/fireviewer-frontend/tree/main/docs) |
| Backend | [`fireviewer-backend/docs`](https://github.com/fireviewer/fireviewer-backend/tree/main/docs) |
| AI worker | [`fireviewer-ai-worker/docs`](https://github.com/fireviewer/fireviewer-ai-worker/tree/main/docs) |
| Spatial / Map Builder | [`fireviewer-spatial/docs`](https://github.com/fireviewer/fireviewer-spatial/tree/main/docs) and [`infra/aws-map-builder`](https://github.com/fireviewer/fireviewer-spatial/tree/main/infra/aws-map-builder) |
| Synthetic data | [`fireviewer-sdg/docs`](https://github.com/fireviewer/fireviewer-sdg/tree/main/docs) |

Tracked component documentation must not contain private working notes, raw
validation output, personal paths, credentials, incident evidence or unreviewed
deployment instructions. Those records belong only in the local working-doc
area. Public claims and cross-repository contracts remain governed by the
[public documentation](../public/README.md) and the [repository documentation
policy](../REPOSITORY_DOCUMENTATION_POLICY.md).
