# FireViewer developer documentation

Developer documentation is owned by the repository that implements the
component. This repository keeps only the cross-project doctrine, contracts and
public status. It does not mirror component runbooks because copied snapshots
drift away from the code they describe.

| Component | Developer documentation |
| --- | --- |
| Frontend | [`fireviewer-frontend/docs`](https://github.com/fireviewer/fireviewer-frontend/tree/main/docs) |
| Backend | [`fireviewer-backend/docs`](https://github.com/fireviewer/fireviewer-backend/tree/main/docs) |
| AI worker | [`fireviewer-ai-worker/docs`](https://github.com/fireviewer/fireviewer-ai-worker/tree/main/docs) |
| Spatial / Map Builder | [`fireviewer-spatial/docs`](https://github.com/fireviewer/fireviewer-spatial/tree/main/docs) and [`infra/aws-map-builder`](https://github.com/fireviewer/fireviewer-spatial/tree/main/infra/aws-map-builder) |
| Synthetic data | [`fireviewer-sdg/docs`](https://github.com/fireviewer/fireviewer-sdg/tree/main/docs) |

Repository-local documentation includes setup, tests, implementation details,
deployment procedures, runbooks and component-specific evidence. Public claims
and cross-repository contracts remain governed by the [public documentation](../public/README.md)
and the [repository documentation policy](../REPOSITORY_DOCUMENTATION_POLICY.md).
